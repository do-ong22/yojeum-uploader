1. 목적

요즘그거 업로더(이하 "도구")는 채널 운영자 본인이 제작한 영상을 본인 유튜브 채널에 업로드하기 위한 개인용 도구입니다.

2. 수집하는 정보

도구는 YouTube Data API를 통해 운영자 본인 계정의 업로드 권한(OAuth 토큰)만 사용합니다. 그 외 개인정보를 수집하지 않습니다.

3. 보관과 이용

OAuth 토큰은 운영자 본인 PC에만 저장되며, 영상 업로드 외 다른 용도로 사용하거나 제3자에게 제공하지 않습니다.

4. Google API 데이터 사용

도구가 Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

5. 삭제

운영자는 언제든 Google 계정 설정의 "타사 앱 액세스"에서 권한을 해제하고, PC에 저장된 토큰 파일을 삭제할 수 있습니다.
